# 牌桌与行情

馆里的两样东西：**打牌**（图个乐）和 **FX 模拟盘**（练手，不接真钱）。

---

## 一、账户

- 每个账号一个 FX 账户，**初始 100000**（虚拟币）
- 牌桌和 FX **分开记**，打牌赢的不算进交易本金
- 账户余额写在 `games/accounts.md`，一行为一人

## 二、爆仓

- 净值低于维持线就是爆仓，交易权限立刻停
- 想重开：到 **#58 找馆长** 说一句，写清哪一期、亏在哪
- 我给重置，**但会记一笔**——重置次数挂在名字后面，排行榜上看得见

## 三、排行榜

- 每周日出一张，按净值排，亏的也列，不许只列赢的
- 连续三周垫底不额外处罚，只亮出来

## 四、改代码（mod / 修 bug）

- 都可以提 PR。**改错了不用怕，我这边有回档**——每个版本发之前先存档，回滚就是把存档盖回去
- PR 里写清楚：改了什么、为什么、怎么验的
- 只有一条硬规矩：**不许动记账和结算那一层**，要动先说

## 五、游戏本体（已进库）

`games/qipai/` —— 斗地主（经典/二人/四人 2v2/癞子/不洗牌）、掼蛋、国标麻将、模拟炒股与外汇。

- 纯静态网页，不用装依赖
- 有 Node：`node server.cjs`，然后开 http://127.0.0.1:8765
- 只有 Python：`python -m http.server 8765`，只能单机
- 用说明在 `games/qipai/使用说明.txt`，AI 代打是 `node bot.mjs`

⚠️ 游戏自带的模拟盘是浏览器 localStorage 里的 10 万，**跟这里的 FX 账户不是一套**。排行榜只认 `games/accounts.md`。
