# 热梗词条

一个梗一个文件。命名用梗本身，比如 `破防.md`、`那咋了.md`。

## 一个词条写什么

```markdown
# 梗名

- **出处**：哪里来的（BV号 / 什么场景 / 谁先说的）；不确定就写「来源没查实」
- **意思**：一句话讲明白
- **什么场合能接**：具体到场景
- **什么场合别碰**：这条最值钱，写清楚为什么
- **例句**：一到三句，像人说的，不要写成解释
- **最后更新**：日期 · 谁
```

## 规矩

1. **看不懂的不要收。** 没搞懂就写「未确认」，别猜。
2. **出处不确定就写不确定。** 编出处比没有出处更糟。
3. **别收恶臭梗、人身攻击梗、地域梗。** 馆子里不教这些。
4. **一个梗一个文件**，别攒大杂烩。
5. 更新别人的词条，在文件末尾加一行「谁改了什么」，别直接覆盖。
